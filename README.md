# billing — ใบส่งของ → invoice

ต่อยอดจากใบส่งของของ [`plan`](https://github.com/nse-manufac/plan) ให้ไปจบที่ invoice
ใช้ร่วมกันสองที่ — **แม่สอด** ส่งของ · **กรุงเทพ** ออกเอกสาร

> **สถานะ: เพิ่งเริ่ม มีแค่หน้าทะเบียนใบส่งของ** · ขั้นตอนการทำงานฝั่ง invoice ยังไม่สรุป
> บันทึกการออกแบบและสิ่งที่ยังไม่รู้ อยู่ใน repo `intake` ที่ `status/billing.md`

---

## ทำอะไรได้แล้วตอนนี้

**หน้าทะเบียนใบส่งของ** — ดึงใบส่งของที่ออกจาก `plan` มาแสดงเป็นรายการ
เพื่อให้กรุงเทพเรียกดูแล้วไปกรอกส่วนของตัวเองต่อในไฟล์ Excel

- ค้นหาด้วยเลขที่ใบ · เลข PO · P/N · หมายเหตุ
- กรองตามหน่วย · ช่วงวันที่ · ออกเลขใบแล้วหรือยัง
- กดที่ใบเพื่อดูรายการย่อยทั้งหมดของใบนั้น (ราย PO · ราย P/N · กล่อง · เศษ · ยอดส่ง)

**ยังไม่ได้ทำ** — ปุ่มออกไฟล์ Excel พร้อมช่องฝั่งกรุงเทพ · ทุกอย่างที่เกี่ยวกับ invoice

---

## ทำไมเป็นแอปแยก ไม่ใช่แท็บใหม่ใน `plan`

`plan` มีกฎล็อกไว้ว่า **ต้องทำงานได้แม้ไม่มีอินเทอร์เน็ต** (มีเทสตัดเน็ตคุมอยู่)
ส่วนแอปนี้ต้อง **ออนไลน์เป็นหลัก** เพราะสองสาขาต้องเห็นของกันและกันโดยไม่ต้องกดซิงค์

สองข้อนี้อยู่ในแอปเดียวกันไม่ได้ จึงต้องแยก

**ข้อมูลไม่ได้ถูกคัดลอกมา** — แอปนี้อ่านตาราง `DeliveryNotes` จาก Google Sheets ไฟล์เดียวกับที่
`plan` เขียนอยู่แล้ว และ **อ่านอย่างเดียว** (INVARIANTS A3) ใบส่งของยังมีต้นทางเดียวเหมือนเดิม

---

## เปิดใช้ยังไง

เป็น ES module จึง **ต้องเสิร์ฟผ่าน http** เปิดไฟล์ตรง ๆ ไม่ได้

```bash
node tests/server.cjs 8126
```

แล้วเปิด http://localhost:8126/index.html

ครั้งแรกให้กด **ตั้งค่าการเชื่อมต่อ** แล้วใส่ URL กับรหัสผ่าน **ชุดเดียวกับที่กรอกใน `plan`**
เก็บไว้ในเครื่องนั้นเท่านั้น ไม่ได้อยู่ในโค้ดและไม่ได้ส่งไปไหน (INVARIANTS D1)

---

## โครงไฟล์

แยกโมดูลตั้งแต่ไฟล์แรกโดยตั้งใจ — ไม่ใช่ไฟล์เดียวแล้วค่อยมาแยกทีหลังแบบ `plan`

```
billing/
├── index.html            หน้าจอ (template + style)
├── app.js                ต่อสายอย่างเดียว — ห้ามมีกฎธุรกิจ
├── core/
│   └── delivery.js       กฎล้วน — ไม่แตะ DOM · เครือข่าย · ที่เก็บข้อมูล
├── io/
│   ├── gs-api.js         คุยกับ Apps Script
│   └── settings.js       การตั้งค่าของเครื่องนี้
└── tests/
    ├── delivery.test.mjs เทส node ล้วน
    └── server.cjs        เสิร์ฟไฟล์ตอนพัฒนา
```

**กฎข้อเดียวที่สำคัญที่สุดของโครงนี้** — ตรรกะธุรกิจอยู่ใน `core/` เท่านั้น
นั่นคือสิ่งที่ทำให้เทสด้วย node ล้วนได้ และย้ายไปแพลตฟอร์มอื่นทีหลังได้โดยไม่ต้องเขียนใหม่

## เทส

```bash
npm test
```

รันด้วย node ล้วน ไม่ต้องเปิดเบราว์เซอร์ ไม่ถึงสิบวินาที
ชื่อเทสอ้างรหัสข้อใน [INVARIANTS.md](INVARIANTS.md) ตรง ๆ — เทสแดงข้อไหน ให้ไปอ่านกฎข้อนั้นก่อนแก้

**สิ่งที่เทสยังตรวจแทนตาไม่ได้** คือหน้าจอ ถ้าแก้ template ต้องเปิดดูเองทั้งบนจอคอมและบนมือถือ
